# Voxline UI 页面需求

## 产品与平台

Voxline 是个人使用的原生音视频字幕应用。

- Mac 首版：本地音视频批处理、转写、翻译、应用内播放校对、SRT 导出。
- iOS 后续：手动导入媒体与字幕成果、原生播放、字幕校对、本地保存。
- 平台仅 macOS 与 iOS。Mac 基线 macOS 15；iOS 后续目标 iOS 18 及以上。
- 界面主题为 Liquid Glass；系统 26 及以上使用原生玻璃，旧系统使用原生材质。

页面范围依据 [首版需求](voxline-v1.md) 与 [Task 工作流决定](../ADR/0004-task-workflow-and-native-design.md)。

## 核心对象与流程

Task 是一批音视频的处理任务，包含任务名称、有序媒体列表、本次参数和处理状态。每个媒体独立保存处理结果、字幕、错误与校对记录。

主流程：任务列表 → 新建任务 → 加入本地媒体 → 选择本次参数 → 开始顺序处理 → 任务详情 → 已完成媒体详情 → 播放校对 → 导出字幕。

- 视频输入：MP4、MOV、M4V；音频输入：M4A、MP3、WAV。是否支持以实际解码能力为准。
- 本地模型负责转写；OpenAI 兼容服务负责翻译。音频留在本地，开启翻译时发送字幕文本。
- 参数在开始时固定；修改全局设置不改变已开始任务。不同参数通过明确重跑或新建任务使用。
- 媒体顺序处理；单项失败继续其余条目。已完成媒体可进入详情，其他媒体可继续处理。
- 任务、结果与校对记录本地保存；退出后保留已完成工作，重启可继续未完成部分。

## Mac 页面

### 1. 任务列表

| 内容 | 要求 |
| --- | --- |
| 任务信息 | 名称、媒体数量、整体状态、真实处理进度、完成／失败数量 |
| 操作 | 新建任务、打开任务详情、进入模型管理与设置 |
| 空状态 | 无任务时显示新建任务入口 |
| 恢复状态 | 中断任务显示待恢复，提供继续处理入口 |

### 2. 新建任务

| 区域 | 内容与操作 |
| --- | --- |
| 基本信息 | 任务名称 |
| 媒体列表 | 多选本地音视频；展示顺序、文件名、音频／视频类型、时长、音轨语言、可用状态；开始前可移除条目 |
| 音轨选择 | 多音轨媒体明确选择处理音轨；展示语言与编码；未选择时提示 |
| 转写参数 | 本次转写模型、原文语言 |
| 翻译参数 | 是否翻译、服务、翻译模型、目标语言；关闭翻译时相关参数不可操作 |
| 输出参数 | 原文 SRT、译文 SRT、双语 SRT；未开启翻译时仅原文可用 |
| 开始操作 | 显示本次参数和媒体数量，开始处理 |

目标使用场景为英语电影／课程转简体中文字幕。

开始前展示实际不可用原因：无有效媒体、音轨未选、无法解码、模型未就绪、翻译配置缺失。不支持的媒体保留错误提示，可移除；其他有效媒体仍可组成任务。开启翻译时说明字幕文本发送到所选服务。

### 3. 任务详情

| 区域 | 内容与操作 |
| --- | --- |
| 任务概览 | 名称、媒体数量、整体状态、真实进度、完成／失败数量 |
| 本次参数 | 只读展示实际转写模型、原文语言、翻译开关、服务、翻译模型、目标语言、输出类型 |
| 媒体队列 | 按顺序显示文件名、类型、时长、处理音轨、当前阶段、进度、状态、失败原因 |
| 任务操作 | 取消任务、继续中断任务 |
| 单项操作 | 取消条目、重试失败／取消条目、进入已完成媒体详情 |

取消保留已提交成果；继续处理跳过已完成部分。部分失败必须与全部完成区分。重试和后台处理不能覆盖较新的手工校对。

### 4. 媒体详情与字幕校对

播放与字幕编辑位于同一页面。

| 区域 | 内容与操作 |
| --- | --- |
| 媒体信息 | 文件名、类型、时长、处理音轨 |
| 视频播放 | 原生视频画面、播放／暂停、进度拖动、当前时间／总时长、活动字幕 |
| 音频播放 | 播放／暂停、进度拖动、当前时间／总时长、活动字幕 |
| 字幕预览 | 原文、译文、双语模式；未生成译文时说明原因 |
| 字幕列表 | 时间、原文、译文、当前播放条目、待重译状态 |
| 校对操作 | 编辑原文／译文、点击字幕定位播放、保存编辑、整体时间偏移 |
| 导出操作 | 打开 SRT 导出面板 |
| 文件异常 | 显示媒体缺失、访问失败或无法播放原因；提供重新关联入口 |

播放音轨与转写音轨一致。修改原文后，对应译文标记待重译；重译覆盖手工译文前提供明确选择。整体偏移作用于当前媒体全部字幕；产生负时间、倒置或超出媒体范围时显示错误。

### 5. 模型管理

| 内容 | 要求 |
| --- | --- |
| 模型信息 | 名称、版本、本地空间占用、可用状态 |
| 状态 | 未下载、下载中、已就绪、加载中、下载失败、损坏 |
| 操作 | 下载、取消下载、失败后重试、损坏后重新下载、删除未使用模型 |
| 异常 | 网络错误、空间不足、文件不完整或损坏均显示实际原因 |

任务创建页选择本次模型；模型不可用时显示状态和管理入口。

### 6. 设置：翻译服务

| 内容 | 要求 |
| --- | --- |
| 服务配置 | 服务名称、OpenAI 兼容接口地址、模型、API 密钥 |
| 操作 | 配置并保存服务，供任务创建页选择 |
| 密钥显示 | 输入内容遮挡；密钥不出现在任务详情与导出内容中 |
| 异常 | 配置缺失、鉴权失败、连接失败、服务不可用显示实际原因 |

服务设置变化仅影响后续任务。本次任务所用服务与模型在任务创建页选择。

## 面板与状态

| 面板 | 内容与操作 |
| --- | --- |
| SRT 导出 | 原文／译文／双语类型、文件名、保存目录、导出；覆盖已有文件时确认 |
| 整体时间偏移 | 当前媒体全部字幕的提前／延后时间、应用、取消、非法时间提示 |
| 媒体重新关联 | 选择本地文件、检查可用性、明确音轨、显示关联失败原因；保留原字幕与校对 |
| 重译覆盖选择 | 显示将受影响的手工译文，明确是否覆盖 |

字幕文件采用 UTF-8，文件名便于与媒体关联。未生成、未完成或失效的译文不能作为有效译文导出；原文导出独立可用。

| 对象 | 需要设计的状态 |
| --- | --- |
| 任务 | 待处理、处理中、全部完成、部分失败、失败、已取消、待恢复 |
| 媒体 | 待处理、音频提取中、转写中、翻译中、已完成、失败、已取消、待恢复 |
| 文件 | 可用、未选音轨、不支持、缺失、访问失败、关联失败 |
| 字幕 | 无字幕、可编辑、无译文、待重译、导出错误 |

旧单媒体文档迁移后，已有成果显示“待确认”，保留字幕并允许浏览和重新关联；没有执行完成证据时不显示为处理完成。

进度依据实际处理状态。错误显示原因和可执行操作；单项失败与任务整体状态分别展示。

## iOS 后续页面

| 页面 | 内容与操作 |
| --- | --- |
| 本地任务／媒体列表 | 展示导入任务与媒体，打开媒体详情 |
| 文件导入 | 手动选择本地媒体及字幕成果，显示关联与可用状态 |
| 媒体详情与校对 | 原生音视频播放、字幕预览与定位、原文／译文编辑、整体时间偏移、本地保存 |

iOS 首轮交付播放与校对；媒体和成果通过手动文件导入取得。

## 视觉规范

- 使用 Apple 原生导航、侧栏、列表、工具栏、sheet、文件选择器和播放器。
- Liquid Glass 用于导航与控制区域；媒体画面、字幕正文和编辑区域保证对比度与可读性。
- 系统 26 及以上使用原生 Liquid Glass；旧系统使用原生 Material。
- 支持系统减少透明度、减少动态效果设置。
- Mac 页面适配窗口尺寸变化；iOS 页面适配触摸交互。
- 操作直接，保留实际错误、覆盖选择和恢复入口；不增加账户、权限角色或重复授权步骤。
