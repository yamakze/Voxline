# Voxline 产品需求与设计规格

Voxline 的产品灵感源自优秀开源项目 [妙幕 (SmartSub)](https://github.com/buxuku/SmartSub)。本项目在此基础上，为 Apple 生态（macOS 15+ 与 iOS 18+）量身定制，强调 **Apple 原生质感与系统级能力**，并提供**全端侧离线闭环处理**的完整字幕工作流。

---

## 1. 产品定位与核心体验

### 1.1 使用场景
支持从导入本地音视频、离线高精度转写、上下文感知翻译、音画同步沉浸校对，到最终导出外挂 SRT、无损内封软字幕与 GPU 硬字幕压制。

### 1.2 核心设计原则
1. **纯粹 Apple 原生质感**：界面全面采用 SwiftUI 编写，深度融入 Liquid Glass 流体玻璃材质、系统动态层级、原生 AVPlayer 播放器与 HIG 快捷键交互。
2. **全端侧离线与极致隐私**：支持在设备本地完成端侧 WhisperKit 语音转写与 Apple 本机翻译，媒体与台词全程不离设备，离线状态下即可完整运行。
3. **不可变快照与成果保护**：任务参数一经启动即冻结快照；检查点原子落盘，迟到的网络响应或外部回调绝不覆盖用户最新手工校对。
4. **轻量直接，拒绝过度设计**：不引入复杂账户体系、云端租约或多余的全局策略层；专注单设备与个人跨设备文件级协同。

## 2. 核心工作流与功能规格

### 2.1 任务批量流水线
- **媒体导入**：支持多选本地音频与视频文件（MP4、MOV、M4V、M4A、MP3、WAV）。
- **媒体检测**：自动读取容器格式、时长、体积与多语言音轨。多音轨媒体必须由用户显式选择处理音轨；单音轨自动选定。
- **任务配置**：每个任务独立配置转写模型、原文语言（或自动识别）、翻译开关、翻译引擎及目标语言。

### 2.2 双轨语音转写
- **端侧 WhisperKit 转写（默认优先）**：
  - 集成 Core ML 加速的 WhisperKit 引擎，支持 Tiny、Base、Small、Large v3、Turbo 5 款模型。
  - 模型按需下载至沙盒，本地磁盘缓存，单一实例内存驻留并自动卸载。
- **云端转写补充（可选）**：
  - 针对低算力设备或批量需求，支持 OpenAI Audio Transcriptions（`/v1/audio/transcriptions`）、Google Gemini 音频聊天与阿里云百炼 Qwen 音频聊天协议。

### 2.3 双引擎智能翻译
- **Apple 本机翻译（全端侧离线）**：
  - 利用系统已安装语言包进行离线翻译，免配置 API Key，零网络消耗，高效安全。
  - 未安装语言包时引导用户通过系统面板下载。
- **OpenAI 兼容 LLM 翻译**：
  - 支持前后滑动上下文（前后各 2 句）以保障对白连贯性。
  - 支持自定义单批字幕数量（默认 30 句）与专属系统提示词（定制语气、术语风格）。

### 2.4 沉浸式双语校对播放器
- **音画同步播放**：基于原生 AVPlayer 构建，提供原文、译文与双语对照三种视图；支持 0.5x ~ 2.0x 变速回放与 ±5s 快速跳转。
- **毫秒级定位跳转**：轻点任意字幕条目，播放器瞬间 Seek 至对应起止时间；纯音频媒体提供声波视图。
- **时间轴与结构编辑**：
  - 单句插入与删除；
  - 逐句起止时间毫秒级微调；
  - 基于标点中点与时间中点的自然断句拆分；
  - 相邻字幕一键合并；
  - 整轨字幕全局时间轴平移偏移。

### 2.5 字幕导出与视频封装
- **SRT 导出**：支持随时导出原文、译文或双语外挂 `.srt` 文件。
- **内封软字幕**：使用 `AVAssetWriter` 将字幕打包为独立 tx3g 轨道并封装为 MP4，无损直通原始音视频画面，毫秒级完成。
- **硬字幕压制**：基于 Core Image 滤镜与 `AVAssetExportSession` 进行 GPU 逐帧渲染烧录，支持自定义字体、字号、自动换行与边距。

## 3. 页面交互规格

### 3.1 任务列表（Task Library）
- **展示**：任务名称、媒体文件数量、整体处理状态、真实进度条、成功/失败计数。
- **操作**：新建任务、打开任务详情、模型管理入口、设置入口；支持原生右键/长按删除任务与拖拽排序。
- **状态流转**：已就绪、处理中、全部完成、部分失败、已取消、待恢复、翻译暂停。

### 3.2 任务配置（Task Configuration）
- 采用 `TaskConfigurationSession` 驱动，表单草稿与媒体访问独立隔离。
- 展示所选媒体列表（文件名、类型、时长、可用状态）。
- 转写与翻译参数联动：关闭翻译时禁用翻译参数；开启时说明文本去向。
- 启动前校验：无可用媒体、音轨未选、模型未就绪或翻译配置缺失时给出明确提示。

### 3.3 任务详情与队列控制（Task Detail）
- 展示当前任务冻结参数快照。
- 媒体列表按序展示当前阶段（提取中、转写中、翻译中、已完成、失败）。
- 控制入口：全局暂停/继续、全局取消；单条目重试、单条目取消、单条目进入校对。
- **停止后参数调整**：任务停止后支持修改参数快照；更换目标语言前明确提示清除旧译文，保留原文与时间轴。

### 3.4 媒体详情与校对视图（Proofreading & Player）
- 播放控制栏：播放/暂停、Slider 拖动 Seek、当前时间与总时长、倍速切换（0.5x、0.75x、1.0x、1.25x、1.5x、2.0x）。
- 双语字幕行：轻点高亮跟随播放器时钟；单句支持行内编辑、单句重译、拆分与合并操作。
- 顶部快捷栏：导出面板入口、全局时间轴平移弹窗、视频压制与封装入口。

### 3.5 模型管理（Model Management）
- 清晰列出 Large v3、Turbo、Base、Small、Tiny 5 种官方推荐模型。
- 显示当前状态：未下载、下载中（进度与速度）、已就绪、校验中、失败。
- 支持单项下载、取消、删除模型文件，直观展示每个模型的本地磁盘占用大小。

### 3.6 设置（Settings）
- **翻译服务**：配置 OpenAI 兼容服务（服务名称、Base URL、模型 ID、API Key、每批字幕数、系统提示词），支持连通性测试。
- **云端转写**：配置 OpenAI Audio Transcriptions、Gemini 或百炼 Qwen 协议及对应凭据。
- **iCloud 同步**：用户指定授权的 iCloud Drive 共享文件夹，支持任务文档与字幕跨设备同步，源媒体同步单独按需开启。

## 4. 视觉与原生设计系统

- **材质与分层**：
  - macOS 15+ 与 iOS 18+ 原生适配；系统 26+ 使用 Liquid Glass 流体玻璃，旧系统使用原生 Material。
  - 字幕浮层与播放面板注重高对比度与文字易读性。
- **系统辅助功能支持**：
  - 完整适配深色模式（Dark Mode）。
  - 所有图标按钮配备本地化 `accessibilityLabel`，完美支持 VoiceOver。
  - 严格响应系统「减少动态效果」（Reduce Motion）与「减少透明度」（Reduce Transparency）设置。
