# Voxline 产品与页面需求

状态：Task 批处理需求已接受；Mac MVP 优先，iOS 原生播放与校对随后交付。

规划与执行状态以 [GitHub Project](https://github.com/users/yamakze/projects/1/views/1) 为准。长期决定见 [ADR-0004](../ADR/0004-task-workflow-and-native-design.md)。

## 产品目标

Voxline 面向个人的音视频字幕工作流：创建任务、加入一批本地媒体、选择本次参数、排队转写与翻译，完成后进入单个媒体详情播放校对，导出外挂字幕。

产品平台限定 macOS 与 iOS，使用 SwiftUI、AVFoundation 和平台原生能力。Mac MVP 完成批处理与播放校对；iOS 随后交付原生播放与校对。Windows、Linux、Android 和 Web 不在产品范围内。

## 首版范围

- 来源仅限本地文件；视频为 MP4/MOV/M4V，独立音频为 M4A/MP3/WAV。实际编码与解码能力在导入时检查。
- Task 是一批媒体的处理队列；每个媒体条目有独立音轨、处理状态、结果、字幕和校对入口。
- 开始前选择本次转写模型、原文语言、是否翻译、翻译服务与模型、目标语言及 SRT 导出类型。密钥由本地服务配置引用，不重复保存在任务参数中。
- 开始后保存实际参数快照；更改服务默认值不改变已开始任务。需要不同处理参数时明确重跑或新建任务。
- 首版采用单执行队列，媒体按顺序处理；单项失败保留原因并继续其他条目，可对失败或取消条目明确重试。
- 本地 WhisperKit 转写，OpenAI 兼容聊天 API 上下文翻译。首版 A 路线只外发字幕文本；音频保持本地。
- 已完成转写分段和翻译批次持久保存，重启后继续未完成工作；不把执行中状态当作已完成成果。
- 媒体处理完成后进入详情：音视频播放、字幕叠加、点击字幕定位、原文／译文编辑和整体时间偏移。音频详情同样可播放，无需虚构视频画面。
- 导出原文、译文、双语三种 SRT；译文与双语要求对应译文有效。
- 任务、结果和校对记录保存在本地。iCloud 同步、云端冲突处理和同步范围设置暂废弃，不进入当前交付。

## Mac 页面

### 1. 任务列表

| 内容 | 要求 |
| --- | --- |
| 任务信息 | 名称、媒体数量、整体状态、真实处理进度、完成／失败数量 |
| 操作 | 新建任务、打开任务详情、进入模型管理与设置 |
| 空状态 | 无任务时显示新建任务入口 |
| 恢复状态 | 中断任务显示待恢复，提供继续处理入口 |

### 2. 新建任务

| 区域 | 内容与操作 |
| --- | --- |
| 基本信息 | 任务名称 |
| 媒体列表 | 多选本地音视频；展示顺序、文件名、音频／视频类型、时长、音轨语言、可用状态；开始前可移除条目 |
| 音轨选择 | 多音轨媒体明确选择处理音轨；展示语言与编码；未选择时提示 |
| 转写参数 | 本次转写模型、原文语言 |
| 翻译参数 | 是否翻译、服务、翻译模型、目标语言；关闭翻译时相关参数不可操作 |
| 输出参数 | 原文 SRT、译文 SRT、双语 SRT；未开启翻译时仅原文可用 |
| 开始操作 | 显示本次参数和媒体数量，开始处理 |

目标使用场景为英语电影／课程转简体中文字幕。

开始前展示实际不可用原因：无有效媒体、音轨未选、无法解码、模型未就绪、翻译配置缺失。不支持的媒体保留错误提示，可移除；其他有效媒体仍可组成任务。开启翻译时说明字幕文本发送到所选服务。

### 3. 任务详情

| 区域 | 内容与操作 |
| --- | --- |
| 任务概览 | 名称、媒体数量、整体状态、真实进度、完成／失败数量 |
| 本次参数 | 只读展示实际转写模型、原文语言、翻译开关、服务、翻译模型、目标语言、输出类型 |
| 媒体队列 | 按顺序显示文件名、类型、时长、处理音轨、当前阶段、进度、状态、失败原因 |
| 任务操作 | 取消任务、继续中断任务 |
| 单项操作 | 取消条目、重试失败／取消条目、进入已完成媒体详情 |

取消保留已提交成果；继续处理跳过已完成部分。部分失败必须与全部完成区分。重试和后台处理不能覆盖较新的手工校对。

### 4. 媒体详情与字幕校对

播放与字幕编辑位于同一页面。

| 区域 | 内容与操作 |
| --- | --- |
| 媒体信息 | 文件名、类型、时长、处理音轨 |
| 视频播放 | 原生视频画面、播放／暂停、进度拖动、当前时间／总时长、活动字幕 |
| 音频播放 | 播放／暂停、进度拖动、当前时间／总时长、活动字幕 |
| 字幕预览 | 原文、译文、双语模式；未生成译文时说明原因 |
| 字幕列表 | 时间、原文、译文、当前播放条目、待重译状态 |
| 校对操作 | 编辑原文／译文、点击字幕定位播放、保存编辑、整体时间偏移 |
| 导出操作 | 打开 SRT 导出面板 |
| 文件异常 | 显示媒体缺失、访问失败或无法播放原因；提供重新关联入口 |

播放音轨与转写音轨一致。修改原文后，对应译文标记待重译；重译覆盖手工译文前提供明确选择。整体偏移作用于当前媒体全部字幕；产生负时间、倒置或超出媒体范围时显示错误。

### 5. 模型管理

| 内容 | 要求 |
| --- | --- |
| 模型信息 | 名称、版本、本地空间占用、可用状态 |
| 状态 | 未下载、下载中、校验中、已安装未加载、加载中、已加载、取消中、已取消、失败、损坏 |
| 操作 | 下载、取消下载、重新下载、验证并加载、卸载、删除未使用模型 |
| 异常 | 网络错误、空间不足、文件不完整或损坏均显示实际原因 |

任务创建页选择本次模型；模型不可用时显示状态和管理入口。

### 6. 设置：翻译服务

| 内容 | 要求 |
| --- | --- |
| 服务配置 | 服务名称、OpenAI 兼容接口地址、模型、API 密钥 |
| 操作 | 配置并保存服务，供任务创建页选择 |
| 密钥显示 | 输入内容遮挡；密钥不出现在任务详情与导出内容中 |
| 异常 | 配置缺失、鉴权失败、连接失败、服务不可用显示实际原因 |

服务设置变化仅影响后续任务。本次任务所用服务与模型在任务创建页选择。

## 面板与状态

| 面板 | 内容与操作 |
| --- | --- |
| SRT 导出 | 原文／译文／双语类型、文件名、保存目录、导出；覆盖已有文件时确认 |
| 整体时间偏移 | 当前媒体全部字幕的提前／延后时间、应用、取消、非法时间提示 |
| 媒体重新关联 | 选择本地文件、检查可用性、明确音轨、显示关联失败原因；保留原字幕与校对 |
| 重译覆盖选择 | 显示将受影响的手工译文，明确是否覆盖 |

字幕文件采用 UTF-8，文件名便于与媒体关联。未生成、未完成或失效的译文不能作为有效译文导出；原文导出独立可用。

| 对象 | 需要设计的状态 |
| --- | --- |
| 任务 | 待处理、处理中、全部完成、部分失败、失败、已取消、待恢复 |
| 媒体 | 待处理、音频提取中、转写中、翻译中、已完成、失败、已取消、待恢复 |
| 文件 | 可用、未选音轨、不支持、缺失、访问失败、关联失败 |
| 字幕 | 无字幕、可编辑、无译文、待重译、导出错误 |

旧单媒体文档迁移后，已有成果显示“待确认”，保留字幕并允许浏览和重新关联；没有执行完成证据时不显示为处理完成。

进度依据实际处理状态。错误显示原因和可执行操作；单项失败与任务整体状态分别展示。

## iOS 后续页面

| 页面 | 内容与操作 |

| 本地任务／媒体列表 | 展示导入任务与媒体，打开媒体详情 |

## 视觉规范

- 使用 Apple 原生导航、侧栏、列表、工具栏、sheet、文件选择器和播放器。
- Liquid Glass 用于导航与控制区域；媒体画面、字幕正文和编辑区域保证对比度与可读性。
- 系统 26 及以上使用原生 Liquid Glass；旧系统使用原生 Material。
- 支持系统减少透明度、减少动态效果设置。
- Mac 页面适配窗口尺寸变化；iOS 页面适配触摸交互。
- 操作直接，保留实际错误、覆盖选择和恢复入口；不增加账户、权限角色或重复授权步骤。

## 数据和执行边界

Task 记录任务 ID、名称、媒体条目顺序、本次参数快照及可恢复成果。媒体条目记录自身 ID、来源、媒体信息、音轨、处理状态与字幕结果。设备路径、文件访问授权、模型、临时音频及 API 密钥由本地基础设施管理。

现有单媒体 `.voxline` 文档与字幕类型作为迁移输入和可复用成果；Task 成为新工作流的根对象。旧数据迁移必须保留字幕 ID、时间、译文来源版本与校对结果，不为迁移增加长期双重权威存储。

MVP 仅实现本地来源。YouTube URL 是后续已保留来源，届时下载获得本地媒体后进入同一队列；目前不建立通用下载器或站点插件体系。

## 开发约束

禁止过度安全设计。直接解决个人本地批处理中的实际问题，不加入账户、权限角色、跨设备执行租约、云冲突合并、通用策略引擎或未经需求证明的多层配置。

保留沙盒文件访问、原文件不被改写、密钥不进入日志／任务成果、明确错误和中断恢复。媒体哈希只用于实际需要的内容身份或重新关联，不在打开、确认和播放每一步重复扫描整份媒体。翻译 ID 与字幕时间验证、已完成结果恢复和手工编辑保护属于功能正确性，按对应任务实现。

## 验收与后续

真实内容基准仍为英语电影／课程译为简体中文。S001 短样本人工字幕校对已完成；30–120 分钟长视频验证由 VXL-045 暂缓跟踪，不据此声称长视频已验证。

Mac MVP 验收批量本地视频与音频、明确音轨、参数快照、单项失败继续、退出恢复、详情播放校对及三种 SRT。Fig Player 保留为历史对照工具，应用内播放是校对必需能力；外部播放器不代替详情页验收。

iOS 原生播放与校对随后交付，媒体和成果先通过手动文件导入获取；自动同步不作为其前置。iOS 独立转写、长任务后台处理和高级编辑继续暂缓。

后续路线保持 A（本地转写＋API 翻译）→ C（Apple Translation 全本地）→ B（云端转写）。YouTube 来源、VTT、其他翻译服务和字幕烧录视频导出列为后续；烧录范围与前置集中维护于 Project VXL-039；iCloud 仅在重新明确提出同步需求时重启。其他平台已排除。
