# Voxline 产品需求与设计规格

Voxline 面向 Apple 生态（macOS 15+ 与 iOS 18+）设计，采用 SwiftUI 构建原生界面与系统级能力，提供涵盖媒体导入、语音转写、双语翻译、字幕校对与视频导出的完整字幕工作流。

## 产品定位与设计原则

- **原生系统集成**：界面基于 SwiftUI 构建，采用 Liquid Glass 与系统原生 Material 材质分层，深度结合系统 AVPlayer、原生工具栏与平台快捷键体系。
- **端侧处理与本地优先**：支持在设备本地完成 WhisperKit 语音转写与 Apple 本机翻译，媒体文件与台词文本不强制依赖云端，支持完全离线运行。
- **不可变快照与成果保护**：任务启动时冻结当前参数快照；检查点基于原子落盘机制保存，异步回调或迟到的网络响应不覆盖用户的手工编辑内容。
- **轻量文件协同**：不设立中心化账户体系，通过本地文件与标准 iCloud Drive 目录实现个人跨设备协同。

## 核心处理管线能力

### 媒体导入与解析
- **格式支持**：支持音频与视频容器，包含 MP4、MOV、M4V、M4A、MP3、WAV。
- **多音轨检测**：自动读取容器格式、时长与音频轨道。多音轨媒体由用户在配置时显式指定目标音轨；单音轨媒体自动选定。

### 语音转写引擎
- **端侧 WhisperKit（默认）**：
  - 基于 Core ML 硬件加速，提供 Tiny、Base、Small、Large v3、Turbo 5 款模型规格。
  - 模型按需下载至应用沙盒，支持本地磁盘占用统计与删除；同一时间仅保留一个活跃模型实例，空闲时释放内存。
- **云端转写协议（可选）**：
  - 支持 OpenAI Audio Transcriptions（`/v1/audio/transcriptions`）、Google Gemini Audio Chat 与阿里云百炼 Qwen Audio Chat 协议。

### 智能翻译引擎
- **Apple 本机翻译（离线）**：
  - 调用系统级翻译框架，利用本地已下载的语言资源进行无网络翻译。
  - 语言资源未就绪时引导至系统面板完成下载。
- **OpenAI 兼容翻译**：
  - 支持前后双向滑动上下文（前后各 2 句）以辅助对白语境连贯。
  - 支持自定义批大小与系统提示词（用于专业术语与文风约束）。

### 字幕导出与视频封装
- **SRT 外挂字幕**：支持按原文、译文或双语三种模式导出标准 `.srt` 文件。
- **内封软字幕**：使用 `AVAssetWriter` 将字幕写入独立 tx3g 轨道并封装为 MP4 容器，直通音视频原始编码样本，不损画质且无需重编码。
- **视频硬字幕压制**：基于 Core Image 滤镜与 `AVAssetExportSession` 进行 GPU 逐帧渲染烧录，支持自定义字体、字号、自动换行排版与居中对齐，支持 H.264 与 HEVC 编码格式。

## 视图交互与操作规格

### 任务库（Task Library）
- **状态呈现**：展示任务名称、媒体文件计数、整体处理进度条与成功/失败条目数。
- **状态流转**：已就绪、处理中、全部完成、部分失败、已取消、待恢复、翻译暂停。
- **Mac 窗口与快捷键**：
  - ⌘T 新建任务、⌘O 打开任务文件、⌘N 新建标签页、⌘, 打开设置。
  - 标签页独立维护导航状态与校对上下文，切换标签或离开页面时自动保存草稿；保存失败时保留当前页面与编辑草稿。
  - 侧栏提供翻译服务与云端转写管理入口，模型管理与偏好设置收敛在独立设置窗口。

### 任务配置（Task Configuration）
- 采用独立表单会话驱动，表单草稿与本地媒体文件隔离。
- 动态联动：关闭翻译开关时禁用下游翻译参数配置；切换为云端服务时展示数据流向说明。
- 启动前校验：对媒体可用性、音轨选择、模型就绪状态与必要凭据进行完整性检查。

### 任务详情与队列调度（Task Detail）
- 展示当前任务冻结的参数快照。
- 媒体列表按序展示执行阶段（提取中、转写中、翻译中、已完成、失败）。
- 队列控制：支持全局暂停、继续与取消；单个条目支持重试、取消与独立进入校对。
- 停止后参数调整：任务停止后允许修改模型与翻译参数；更换目标语言前提示清除旧译文，保留原文与时间轴数据。

### 双语校对与音画播放（Proofreading & Player）
- **播控交互**：包含播放/暂停、进度滑块 Seek、当前时间与总时长显示、倍速调节（0.5x、0.75x、1.0x、1.25x、1.5x、2.0x）与静音切换。
- **字幕跟随与编辑**：
  - 字幕高亮跟随播放器时间轴，支持轻点单行精准跳转播放进度。
  - 单句支持原文与译文行内编辑、单句重译、拆分与合并。
  - 时间轴微调：支持单句起止毫秒调整与整轨全局时间轴平移。
- **顶部操作入口**：提供 SRT 导出面板、时间偏移面板、软字幕封装与硬字幕烧录入口。

### 模型与服务管理
- **模型管理**：展示 5 种官方推荐模型规格、下载进度、校验状态与沙盒磁盘占用，支持取消与清理。
- **翻译服务配置**：支持录入 OpenAI 兼容服务（Base URL、模型 ID、API Key、批大小、系统提示词），支持连通性测试。
- **云端转写配置**：支持配置 OpenAI Audio、Gemini 或百炼服务协议与 API 凭证。
- **iCloud 同步**：由用户显式授权目标 iCloud Drive 文件夹，实现任务文档与字幕的跨设备同步，源媒体同步单独提供开关。

## 视觉规范与辅助功能

- **材质与分层**：
  - macOS 15+ 与 iOS 18+ 原生适配；macOS 26+ 采用 Liquid Glass 悬浮材质，其余环境适配系统原生 Material。
  - 字幕浮层与播控底栏保障文字阅读与背景视频的高对比度。
- **系统辅助功能支持**：
  - 完整适配系统深色模式（Dark Mode）。
  - 所有图标按钮配备本地化 `accessibilityLabel`，支持 VoiceOver 屏幕朗读。
  - 界面动效严格遵循系统「减少动态效果」（Reduce Motion）与「减少透明度」（Reduce Transparency）设置。
