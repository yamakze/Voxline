# Voxline 产品需求与设计规格

Voxline 面向 Apple 生态（macOS 15+ 与 iOS 18+）设计，采用 SwiftUI 构建原生应用体验，提供涵盖媒体导入、语音转写、双语翻译、字幕校对与视频封装导出的完整字幕工作台。

## 产品定位与核心原则

- **端侧处理与离线优先**：全流程核心能力默认在本地设备闭环运行。基于 WhisperKit Core ML 硬件加速与 Apple 本机翻译，无网络环境下仍可完成完整字幕制作。
- **不可变快照与成果保护**：任务启动即冻结配置快照；转写切片与翻译批次实时原子落盘；异步服务响应不覆盖用户对字幕的手工编辑。
- **去中心化轻量协同**：不设立中心化账号系统与专属服务端点，基于便携式 `.voxline` 本地文档与系统 iCloud Drive 实现多设备文件级协同。
- **平台原生交互质感**：严格遵循 Apple 人机交互界面指南（HIG），深度结合原生 AVPlayer、平台菜单体系、窗口与标签页机制及触控手势。

## 处理管线与交付规格

### 媒体导入与音轨管理
- **容器格式支持**：兼容主流音视频格式，包含 MP4、MOV、M4V、M4A、MP3、WAV。
- **音轨检测与绑定**：导入时自动提取时长、文件大小与音频轨道列表。单音轨媒体默认自动选定；多音轨媒体提供独立选择面板，提取仅针对选定轨道。
- **内封字幕提取**：若输入媒体包含合规的文本字幕轨道，导入时自动解析为初始台词条目，可直接进入校对或作为译文匹配源。

### 语音转写引擎
- **端侧 WhisperKit（默认）**：
  - 提供 5 款官方标准模型：Tiny、Base、Small、Large v3、Turbo。
  - 模型按需从官方源下载至应用沙盒，支持校验和检验、存储空间统计与单项清理。
  - 运行时单模型实例驻留，空闲自动卸载。
- **云端转写协议（可选）**：
  - 支持标准 OpenAI Audio Transcriptions（`/v1/audio/transcriptions`）协议。
  - 兼容 Google Gemini 与阿里云百炼 Qwen 音频理解协议。

### 智能翻译引擎
- **Apple 本机翻译（离线）**：
  - 接入系统翻译框架与本地离线语言包，零配置且无需网络。
  - 缺失目标语言资源时，提供系统资源下载引导。
- **OpenAI 兼容翻译**：
  - 支持标准 Chat Completions 协议，提供模型 ID、Base URL 与 API Key 配置。
  - 具备前后双向滑动上下文机制（前后各 2 句相邻字幕），保持对话逻辑连贯。
  - 支持自定义批大小（10~50 句）与系统提示词（用于控制风格与专有名词约束）。

### 交付物导出规格
- **外挂字幕文件（SRT）**：遵循标准 SubRip 格式，支持原文、译文或双语对照三种导出投影。
- **内封软字幕视频（MP4）**：将字幕写入独立 tx3g 轨道并封装为 MP4 容器，直通音视频原始流，无损且无需重编码。
- **硬字幕压制视频**：调用系统 GPU 逐帧渲染烧录字幕，支持字号缩放、多行居中、底部安全边距设置，提供 H.264 与 HEVC 两种编码规格。

## 视图交互与状态机规范

### 任务库与窗口管理（Task Library）
- **状态流转机制**：任务生命周期包含以下确定状态：
  - `已就绪`（Ready）：媒体与参数配置完成，等待执行；
  - `处理中`（Processing）：队列正在调度提取、转写或翻译；
  - `全部完成`（Completed）：全部条目处理结束，所有产物可交付；
  - `部分失败`（Partially Failed）：部分媒体条目出现异常，其余条目已完成；
  - `已取消`（Cancelled）：用户显式中断执行；
  - `待恢复`（Interrupted）：异常退出或系统中断后的可继续状态；
  - `翻译暂停`（Translation Paused）：转写已完成，因未配置翻译凭据或网络中断挂起。
- **Mac 窗口体系**：
  - 支持多窗口与多标签页操作（⌘T 新建任务，⌘N 新建标签页，⌘O 打开文档，⌘, 打开偏好设置）。
  - 各标签页与独立窗口维护专属导航栈与编辑草稿，切换或离页时自动提交更新。

### 任务参数配置（Task Configuration）
- **会话草稿隔离**：配置面板使用独立表单状态，确认前不修改全局设置或源任务。
- **参数联动逻辑**：
  - 关闭翻译开关时，自动禁用下游翻译参数选择；
  - 选用云端引擎时，展示明确的数据外发提示与凭据状态。
- **运行期修改约束**：任务运行期间锁定关键参数；停止状态下允许变更模型与翻译参数。修改目标语言时弹出二次确认，重置下游译文并保留已有原文时间轴。

### 任务详情与队列调度（Task Detail）
- **串行调度展示**：清晰呈现任务队列中各媒体条目的当前执行阶段（音频提取 → 语音转写 → 双语翻译）。
- **细粒度控制**：支持任务级全局暂停、继续与取消；单个条目支持独立重试、跳过与即时进入校对。

### 双语校对工作台（Proofreading & Player）
- **音画同步播放器**：
  - 集成播放/暂停、±5 秒步进、进度定位（Seek）、当前时间与总时长显示。
  - 支持 0.5x、0.75x、1.0x、1.25x、1.5x、2.0x 六档变速回放；纯音频媒体提供实时声波视图。
- **字幕时间轴联动**：
  - 播放过程中高亮当前字幕行，支持轻点单行精准跳转播放进度。
  - 列表支持手动滚动浏览，滚动期间暂停自动跟随，点击字幕或恢复播放时重新对齐。
- **台词与时间轴编辑**：
  - 支持原文与译文的行内即时编辑与单句重译；
  - 提供单句插入、根据标点中点与时间区间的自然断句拆分、相邻字幕一键合并；
  - 支持单句毫秒级起止时间微调与全局时间轴平移偏移。

### 偏好设置与系统服务
- **模型管理**：展示 5 款推荐模型的下载状态、SHA-256 校验结果与沙盒磁盘占用，支持取消下载与文件彻底清理。
- **服务凭据配置**：集中管理 OpenAI 兼容服务端点与云端转写配置，提供即时连通性测试。凭据均由系统 Keychain 托管，不包含在导出的任务文件中。
- **iCloud 同步**：由用户显式授权目标 iCloud Drive 文件夹，实现任务文档与字幕文本跨设备协同，源媒体同步单独受开关控制。

## 设计系统与平台规范

- **界面材质分层**：
  - macOS 26+ 采用原生 Liquid Glass 悬浮材质，macOS 15+ 采用系统 Material 材质；
  - 播放器字幕遮罩层采用高对比度暗色底衬，保障复杂视频背景下的可读性。
- **系统辅助功能**：
  - 全界面完整适配系统深色模式（Dark Mode）；
  - 全量操作控件配备明确的本地化 `accessibilityLabel`，支持 VoiceOver 屏幕朗读；
  - 响应系统「减少动态效果」（Reduce Motion）与「减少透明度」（Reduce Transparency）设置，降级为静态与高对比度渲染。
