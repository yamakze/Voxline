# M1 视频导入与本地关联验证

日期：2026-10-02。设备为 M4 / 16 GB、macOS 15.7.9、Xcode 26.2 / Swift 6.2.3。

## 实现

视频导入检查实际时长、视频轨、音轨、编码、语言、保护与解码状态，以流式 SHA-256 建立内容身份。确认关联前再次检查文件；关联失败保持文档不变。多音轨必须明确选择，同内容重新关联保留字幕和编辑版本。

只读安全范围书签按项目 ID 原子保存在设备本地；打开项目重新检查实际文件，过期书签经身份校验后更新。系统文档场景与最近文档入口用于项目查找，当前不引入数据库索引。规则见 [ADR-0003](../ADR/0003-local-media-association.md)。

## 验证结果

- `swift test`：16 项、3 个测试组通过，覆盖文档完整性、媒体身份与音轨不符、失败关联不产生部分修改、缺失／损坏记录、错误格式、空文件、损坏媒体、无音轨及原生多语言音轨枚举。
- `Scripts/build-app.sh debug`：生成启用 App Sandbox 的应用；`codesign --verify --deep --strict` 通过。
- S001 MP4：原生界面读取 1077.718 秒、视频轨 2（avc1）、英语音轨 1（AAC），均可解码。已有 208 条字幕的项目无设备记录时明确提示关联；关联成功，退出应用后重新打开可恢复视频访问。
- 一秒 MOV：直接写入 H.264 视频和英语／西班牙语两个 PCM 音轨。界面初始不选音轨且禁止确认；新项目选英语轨 2 后可关联、保存，项目 JSON 保存了对应音轨 ID。
- 内容不符：将该 MOV 关联到 S001 项目时明确拒绝，原项目、字幕与有效本地关联保留。
- 移动与权限：MOV 移动、改名后，重新打开项目的书签解析到新位置；将测试文件设为不可读时显示权限失败与重新关联提示。恢复读取权限并重新选择同文件、同音轨后恢复可用。
- M4V：以 S001 MP4 内容的本地硬链接验证 M4V 扩展名入口、真实媒体读取和同内容重新关联，不复制视频数据。不是另一份独立编码样本。
- 文档检查：两份运行测试项目不包含媒体绝对路径或书签；S001 文档中的 208 条字幕、ID、时间和设置与原夹具一致。

运行夹具、生成器和日志位于忽略目录 `tmp/project-governance/`。测试权限已恢复，原 S001 视频保持原状。
