# M1 Task 文档与迁移验证

日期：2026-10-02。范围：VXL-046，Task 数据、本地文档存储与旧格式迁移。

## 实现

ProcessingTask 作为 `.voxline` 格式版本 2 的根对象，保存有序媒体条目、本次参数和开始时间。参数开始前可通过数据接口修改，冻结后禁止更改；转写支持自动／指定原文语言，翻译设置保存本地服务 ID，输出类型包含原文、译文和双语 SRT。

TaskMediaItem 保存独立 ID、媒体类型、本地来源描述、媒体身份、处理状态及字幕。整体状态与完成／失败数量由条目计算。Task 与旧项目共用字幕时间线验证；旧 SubtitleProject 只用于迁移，不在 Task 中复制一份配置或成果。

应用 FileDocument 使用 TaskDocumentCodec 读写，沿用系统文档存储。任务文档中的侧栏选择绑定到媒体条目，视频导入和设备本地关联复用现有实现。重新打开时运行状态转为待恢复，已提交成果保留。
