# iOS 开发入口验证

日期：2026-10-03。范围：VXL-030 的提前构建／界面开发基础，以及 VXL-047 的开发运行入口。

## 构建与打包

- Xcode 26.2 构建 VoxlineIOS / VoxlineCore，模拟器 Debug 与 iPhoneOS arm64 Release 均成功。
- build-ios-ipa.sh 生成 build/ios/Voxline-unsigned.ipa；ZIP 完整性、Payload/Voxline.app、iPhoneOS 平台、iOS 18 最低版本、Core 嵌入与运行加载路径已检查。
- 应用与 Core 的设备二进制均由 codesign 确认未签名；包不含签名目录、描述文件或 AppleDouble 扩展属性文件。
- 脚本 bash 语法及工程／Info.plist 格式通过；非法平台和配置返回非零。打包使用新临时 Payload，成功后原子替换目标文件。
- 首次模拟器启动发现 Core 使用绝对框架安装路径；修正为 @rpath 后启动成功，设备产物也采用正确加载路径。

## 原生运行

设备：iPhone 17 Pro 模拟器，iOS 26.3。compile_and_run_ios.sh 完成从关闭设备到开机、安装、启动；重复运行替换旧进程并保持本地任务。旧实例 PID 37841，后续实例 38506 / 38977。

- 空任务页面、Files 选择器、原生导航与系统 26 玻璃控件实际显示。
- 同一混合 Task 通过 Files 导入后显示 5 个媒体、0 完成、1 失败；媒体页保留空文件失败原因，未生成处理成果。保存后的任务与原夹具字节一致。
- S001 旧格式文档经同一 TaskDocumentCodec 迁移为版本 2、待确认；208 条字幕、ID、时间、文本与版本字段逐项保持一致。
- 进入 S001 字幕详情，实际显示原文、待翻译状态与毫秒时间，例如 00:00:23.460 → 00:00:23.660。媒体未关联与当前播放／编辑未交付状态明确显示。
- 格式版本 999 的文件导入被拒，原生错误提示说明版本不支持，已有任务保留。
- 重装重启后任务可见；保存文件 SHA-256 比对保持不变。模拟器每次安装可能改变容器路径，检查以 simctl get_app_container 返回路径为准。

## 耗时与缓存

两次无新增 Swift 源码的缓存构建分别约 2 / 3 秒；修改字幕时间格式后的模拟器构建约 4 秒。设备加载路径修正后的缓存构建约 3 秒。数据来自脚本的墙钟整数秒；不代表首构建耗时、不同设备表现或推理性能。

首次构建 Timing Summary 中 SwiftCompile 累计 14.328 秒、资源编译 4.723 秒；并行步骤累计不能直接当成总耗时。device／simulator 独立 DerivedData，iOS 构建不编译 WhisperKit。

## 交付边界

iOS 入口目前是只读任务与字幕浏览、文档导入和本地保存；没有媒体关联、播放、校对、时间定位或导出。完整 VXL-030 验收仍待共享校对能力交付。未进行真实设备签名／安装／运行、iOS 18 或 iPad 运行验收，也未重新执行长视频转写。
