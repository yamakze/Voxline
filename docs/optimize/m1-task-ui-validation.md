# 原生 Task 界面验证

日期：2026-10-02。对应 VXL-047。当前 Mac 界面阶段人工验收完成；队列、播放校对及系统 26 运行验收继续跟踪，Status 为 In Progress。

## 实现范围

- 本地任务列表复用系统最近文档，显示名称、媒体数量、真实状态、完成／失败数量；无独立成果数据库。
- 新建空文档打开任务准备；支持多选 MP4／MOV／M4V、逐项检查、明确选择多音轨、移除未提交文件及调整既有条目顺序。
- 任务准备包含模型、自动／指定原文语言、翻译地址／模型／目标语言与原文／译文／双语 SRT 选择。关闭翻译时恢复原文输出；非法参数明确失败，取消不改变原文档。当前保存配置摘要，不保存密钥，不声称服务或模型可用。
- 准备全部成功后提交同一 Task 绑定；本地书签写入失败不提交任务，等待期间原任务变化则拒绝覆盖。
- 任务概览展示顺序、阶段、失败原因、完成数量与本次参数；每个条目可进入已有字幕详情。重试、处理队列、播放和编辑尚未接通，界面明确说明。
- 导航与控制区域在 macOS 26 使用原生 glassEffect，macOS 15 使用 regularMaterial；减少透明度时使用不透明系统背景。内容区保持标准背景，不添加自定义动态效果。
