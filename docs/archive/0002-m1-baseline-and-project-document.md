# ADR-0002 M1 基线与项目文档

状态：历史决定，相关范围已被 ADR-0004／0005／0006 替代。日期：2026-10-01。

范围更新：Task、平台、同步与媒体扫描策略以 [ADR-0004](../ADR/0004-task-workflow-and-native-design.md) 为准；下文保存原决定及其实施背景。

## 决定

S001 人工字幕校对已完成，作为当前个人使用的短样本推进依据。30–120 分钟验证暂缓，保留独立 Project 条目的原因与重启条件；不推导为长视频已验证。

当前开发基线为 macOS 15 及以上、Apple Silicon，已实测设备为 M4 / 16 GB。其他设备性能与公开支持范围待相应验证。WhisperKit 锁定 v1.1.0，默认模型为 `openai_whisper-large-v3-v20240930_626MB`。M0 的 fullFile + none 作为实现诊断基线；增量读取的有效帧、零时长非空段及失败传播问题由 Provider 任务解决，不自动切换到已知有风险的路径。耗时和内存采用已登记实测，不建立未经验证的硬性承诺。

项目采用版本化 `.voxline` 文档，版本 1 的权威内容为结构化 JSON。项目 ID 与字幕 ID 持久稳定，时间使用绝对毫秒；原文、译文与译文对应的原文版本独立保存。未来格式、损坏数据、重复 ID 与无效时间显式报错。字幕修改增加原文版本；旧译文保留来源并标记失效。

同步文档只保存媒体身份与非敏感配置、结构化字幕和编辑结果。媒体绝对路径、设备书签、模型、密钥、临时文件、执行状态和分段恢复记录保存在设备本地。未关联媒体是可见的文档状态，不使用伪造路径或默认音轨。

产品 SRT 由结构化字幕生成。原文导出只要求源字幕有效；译文和双语导出要求全部对应译文有效，不自动回填原文。双语顺序为原文在上、译文在下。字幕切分使用词、标点和静音边界，显示长度与时长在切分任务中验证；不以更改原始时间掩盖对齐失败。

Mac 校对目标为 Fig Player，iOS 播放器在跨设备验收阶段登记；名称未定不阻塞 Mac 工程与文档基础。公开支持、长视频、播放器、恢复、翻译与 iCloud 的验收证据分别记录。

## 实施边界

M1 从 Mac 工程、核心类型与文档读写开始。文档系统协调保存，Pipeline 通过文档变更提交成果；不直接覆盖受文档系统管理的文件。跨设备冲突在 iCloud 任务中验证，不能仅凭 JSON 编码成功声称同步可靠。

长视频验证的暂缓不移除分段恢复、错误可见和媒体重新关联要求。SDK 接入保持外部边界，Core 与项目格式不暴露 SDK 类型。
