# ADR-0009：真实对齐与可读字幕分开保存

状态：已接受。

SDK 的词级输出适合保存识别证据，逐词导出不适合阅读。原始段也可能缺少词时间；按字符比例拆分会产生无法从音频验证的时间。

可读字幕作为原始证据的派生产物，切分结果携带策略与来源位置。采用真实词边界、标点、静音和显示限制，借鉴 [SmartSub 的聚合与标点回溯思路](https://github.com/buxuku/SmartSub/blob/main/main/helpers/subtitleSegmentation.ts)。其无词时间比例估算不纳入 Voxline；Provider 在词对齐异常时回退到有效段解码时间，无词时间保留整段，不生成强制校对标记。转写与所需翻译完整提交即可使用，校对属于按需编辑。

字幕身份以不可变转写来源与原始位置为基础。人工编辑和翻译必须继续受版本保护；稳定身份不能替代内容版本检查。原始时间与阅读延长后的时间在切分结果中分开表达，完整识别证据保存在设备诊断缓存；Task 保留当前字幕与完成摘要，不依赖完成块的原始证据续跑。未完成识别的恢复证据仍随 Task 保存，持久规则见 [ADR-0010](0010-atomic-task-checkpoints.md)。

当前接口、规则与接入边界统一见 [架构](../architecture/README.md#可读字幕切分)。验收证据与执行状态见 [Project](https://github.com/users/yamakze/projects/1)。
