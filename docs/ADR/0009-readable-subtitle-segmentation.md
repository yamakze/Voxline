# ADR-0009：真实对齐与可读字幕分开保存

状态：已接受。

SDK 的词级输出适合保存识别证据，逐词导出不适合阅读。原始段也可能缺少词时间；按字符比例拆分会产生无法从音频验证的时间。

可读字幕作为原始证据的派生产物，保留切分策略与来源位置。采用真实词边界、标点、静音和显示限制，借鉴 [SmartSub 的聚合与标点回溯思路](https://github.com/buxuku/SmartSub/blob/main/main/helpers/subtitleSegmentation.ts)。其时间修正和无词时间比例估算不纳入 Voxline；异常对齐不修正时间；Provider 回退到段解码时间时整段保留并要求逐句确认，无词时间保留整段并标记需校对。

字幕身份以不可变转写块与原始位置为基础。切分策略可重算，人工编辑和翻译必须继续受版本保护；稳定身份不能替代内容版本检查。原始时间与阅读延长后的时间分开保存，避免调整阅读策略需要重新推理。

当前接口、规则与接入边界统一见 [架构](../architecture/README.md#可读字幕切分)。验收证据与执行状态见 [Project](https://github.com/users/yamakze/projects/1)。
