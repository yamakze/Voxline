# ADR-0007 固定版本模型安装与实例生命周期

状态：接受。日期：2026-10-03。

## 决定

当前提供 S001 已验证的 `openai_whisper-large-v3-v20240930_626MB`，沿用 M4 / 16 GB 的短样本基线。其他型号在完成设备、字幕质量和性能验证后加入；已有 Task 的其他型号保持原值并显示尚未支持，不替换为基准型号。

模型来源为 [argmaxinc/whisperkit-coreml 固定提交](https://huggingface.co/argmaxinc/whisperkit-coreml/tree/0f63a7800b00dd0226abd051b906c246e1907482)。分词器来源为 [openai/whisper-large-v3 固定提交](https://huggingface.co/openai/whisper-large-v3/tree/06f233fe06e710322aca913c1bc4249a0d71fce1)。应用资源 BaselineModel.json 保存仓库、提交、文件清单、长度及仓库对象摘要。权重 17 个文件共 626,718,238 字节，分词器 3 个文件共 2,764,732 字节；下载缓存和安装记录计入本地占用。

每个型号在应用本地 Application Support/Voxline/Models 下拥有独立目录，包含 SDK 仓库缓存、模型、分词器和 installation.json。下载显式指定提交与精确型号路径，避免 SDK 模糊搜索返回另一型号。全部必需文件通过长度和摘要校验后，原子写入安装记录。LFS 文件使用仓库 SHA-256，普通文件使用 Git blob SHA-1；用途为匹配仓库文件身份。

页面刷新检查安装记录、版本及必需文件长度，不重复读取整套权重。下载结束和每次实际加载前做完整摘要校验。已安装与已加载是独立状态：前者可跨进程识别；后者要求当前进程的 WhisperKit 完成 Core ML 加载。同一型号复用一个已加载实例，卸载释放引用，已加载型号禁止删除或重新下载。

分词器从固定本地目录加载，先执行本地解析，解析失败明确退出，再交由 SDK 加载并识别模型结构。SDK 类型和实例留在 VoxlineWhisperKit 内；Task 只保存型号标识。Mac 打包脚本将清单复制到应用 Resources；应用缺少清单时明确报错，不依赖开发目录。

## 下载与恢复

下载进度按 SDK 文件完成比例展示，并区分权重、分词器和校验阶段。取消后等待 SDK 操作结束，再开放重新下载；操作标识隔离迟到回调。SDK 返回部分目录不代表完成，取消检查与完整性校验仍必须通过。

重新下载清理该型号目录并执行完整下载，不承诺断点续传。取消或失败留下的部分文件计入占用，可显式移除。下载前检查可用空间；空间查询、读写、网络和校验错误均显示实际原因。模型与缓存不写入任务文档。

## 验证边界

模型加载成功不代表转写 Provider、Task 队列、恢复或长视频质量通过。实际验证见 [模型安装与加载验证](../optimize/m1-model-installation-validation.md)，转写及恢复分别由 VXL-009／012／026 交付。
