# ADR-0007 多模型安装与实例生命周期

状态：接受。日期：2026-10-03。修订：2026-10-10。

## 决定与理由

模型库提供 Large v3、Turbo、Base、Small、Tiny。2026-10-03 的 S001 单模型验证限制已解除；模型可下载和使用不再要求先取得目标设备性能或人工质量认证。Large v3 使用官方 947MB 路径的压缩型号（32 层解码器）。原有 626 MB 型号实际为 4 层解码器的 Turbo，保留已有安装与任务参数，修正显示名称；不把 626MB 和 turbo_632MB 两个 Turbo 变体重复呈现为不同型号。Base、Small、Tiny 使用多语言版本。

WhisperModels 集中维护实际型号路径、显示信息及上游模型／分词器提交。下载显式指定型号路径和提交，避免 SDK 模糊搜索。安装记录仅保存下载文件的路径和长度；去除手工摘要清单、记录与清单的全等比较及加载前的权重全量扫描，减少维护和磁盘开销。文件缺失／长度变化及实际 Core ML 或分词器解析错误仍明确失败。已安装的模型不因清单提交更新而被强制重新下载。

安装可跨进程识别，加载只代表当前进程中 SDK 实际完成 Core ML 初始化。同型号复用实例；切换型号先释放旧实例，转写按需加载，空闲删除或重新下载时自动释放对应实例。界面统一呈现已就绪，使用者只管理下载文件；取消、占用和删除错误保留真实安装状态。

分词器先解析指定本地文件，再由 SDK 识别模型结构。重新下载为完整安装；取消等待 SDK 结束后才开放下一次操作，部分文件计入占用。当前目录、进度和错误规则统一见 [架构：模型安装与加载](../architecture/README.md#模型安装与加载)。
