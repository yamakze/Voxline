# ADR-0013：Apple 本地翻译与显式引擎快照

状态：接受。

## 决定

在同一 Task 工作流加入 Apple Translation，不建立独立本地翻译队列。翻译快照通过带类型的引擎区分兼容接口与 Apple 参数，文档升级为版本 5；旧版 API 快照保留语义迁移。

macOS 15 使用稳定根视图管理 TranslationSession，macOS 26 的已安装语言可用独立会话。语言下载由明确的语言准备操作和系统面板处理；翻译只使用已安装语言，资源缺失立即显示准备入口，避免在翻译阶段等待系统下载而无法解释进度。取消等待实际操作结束。批量结果通过字幕 ID 交给既有检查点验证与保存。

## 理由

Apple 本地翻译不需要远端服务、密钥或聊天提示词，强行复用这些配置会产生无效组合。视图会话满足基线系统的语言下载和生命周期要求；已有批次及校对版本可继续负责恢复与编辑保护。

Apple 的句子译法可能缺少对白语境，保持引擎可选和播放校对，不把本地成功等同于译文质量通过。失败不切换远端服务。
