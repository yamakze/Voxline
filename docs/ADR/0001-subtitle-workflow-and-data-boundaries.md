# ADR-0001 字幕工作流与数据边界

状态：接受。日期：2026-10-01。

范围更新：Task、平台、同步与媒体扫描策略以 [ADR-0004](0004-task-workflow-and-native-design.md) 为准；下文保存原决定及其实施背景。

## 背景

Voxline 面向个人使用，在 Mac 处理本地无字幕电影或课程，并生成供现有 iOS 播放器使用的外挂字幕。长视频处理成本和手工校对结果需要得到保护。

## 决定

首版处理端为 Mac。转写采用本地 WhisperKit，翻译采用可配置的 OpenAI 兼容 API，交付原文、译文、双语三种 SRT。后续引擎路线依次增加 Apple Translation 全本地处理和云端 ASR 全云端处理。

iCloud 默认同步项目配置、结构化字幕与编辑结果，播放器使用的成品字幕独立保存。原视频、模型、临时音频、API 密钥和设备执行状态保持本地。同步范围后续通过 Settings 配置。

已完成的转写分段和翻译批次持久保存。恢复时检查媒体、音轨、模型和配置的一致性；异常、失败、结果失效和 Provider 切换均需可见。

## 影响

媒体、转写、翻译、字幕编辑和持久化具有明确边界。同步项目需要独立处理媒体重新关联、文件版本冲突和手工编辑保护。模型与运行门槛由 M0 实测决定，文档格式和具体实现由对应任务收敛。

详细范围见 [首版需求](../RFC/voxline-v1.md)，执行与验证记录见 [GitHub Project](https://github.com/users/yamakze/projects/1/views/1)。
