# ADR-0015：iOS 独立处理与 Mac 功能补齐

状态：接受。日期：2026-10-04。

## 决定

iOS 在原生播放校对基础上逐步支持 Mac 的本地 Task 工作流，包括批量媒体准备、模型管理、转写、API 与 Apple 本机翻译、顺序队列、检查点恢复、校对重译、SRT／任务分享和硬字幕视频导出。VXL-031 汇总交付范围，各能力及验收由其关联条目跟踪。

两平台保持同一 Task、字幕版本和处理成果语义。扩展时复用 Core、Media、WhisperKit 与 Translation 能力，将实际需要共用的编排和外部调用从 Mac 界面依赖中移出；原生文件交互、凭据、界面与系统翻译会话由设备本地适配。共享代码边界随实施更新 architecture，不复制第二套队列或恢复协议。

先支持可恢复的前台处理，再按系统和设备资源接入 iOS 26 后台继续。推理、网络翻译、Apple 翻译会话和视频导出分别验证；系统排队、拒绝、到期、取消和进程中断均保留明确状态与恢复入口。模型与处理资源边界依据真机测量确定。

Mac 与 iOS 通过 Files 和原生分享手动交接成果，保持独立设备副本。接收设备重新关联媒体及本机服务，原有 iCloud 暂废弃决定继续适用。

## 理由

独立处理使 iOS 能完成相同字幕工作流；共用成果和执行规则减少平台间差异及重复维护。原生界面适配触摸、横屏和 iPad，不要求复制 Mac 窗口与 Finder 操作。

后台运行由系统资源和生命周期控制，检查点恢复是可靠的交付基础。设备上的模型内存、语言支持与编码能力需要实际验证，不能从 Mac 成功或模拟器构建推断。
