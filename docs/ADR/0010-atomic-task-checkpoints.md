# ADR-0010：检查点与编辑成果在同一 Task 中提交

状态：已接受。

推理缓存可被清理，成功返回的数组也不能代表成果已保存。若检查点与字幕另存两份文件，崩溃可能留下互相不一致的完成标记和编辑内容。

采用版本 3 Task 文档，在单媒体条目内保存处理检查点、原始证据和可编辑字幕。每次完成分块或批次都验证并原子写入同一文件，成功后才向界面发布。旧格式保留身份和成果，缺少执行来源时不虚构检查点。此选择扩展 [ADR-0005](0005-task-document-format.md) 的 Task 格式。

原始切分与当前校对分别保留。已提交结果不可被重试覆盖；翻译使用发送时的文本、版本和译文快照，在提交时保护最新编辑。恢复使用冻结参数、实际媒体与提取范围，跳过完整提交的工作；单进程顺序执行由队列负责，不建立跨设备租约或云冲突协议。

界面与后台提交共用任务库中的当前任务，避免两个活动副本互相覆盖。读写和校对冲突传播为明确错误，保存失败保留内存编辑和最后成功文件。

当前字段、状态与执行边界统一见 [架构](../architecture/README.md#处理检查点与恢复)，验收结果见 [Project](https://github.com/users/yamakze/projects/1)。
