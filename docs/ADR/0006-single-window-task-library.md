# ADR-0006 单窗口任务库与显式持久化

状态：接受。日期：2026-10-03。

## 决定

任务列表、准备表单、任务详情和媒体校对位于同一原生窗口。任务库负责 .voxline 文件生命周期，替代 ADR-0005 中的 DocumentGroup / FileDocument 场景；格式版本 2、参数冻结和旧数据迁移规则继续有效。

新任务保存到应用本地 Application Support/Voxline/Tasks。导入已有任务后，以原文件 URL 为保存目标，不建立第二份成果副本。TaskLibrary 的内存条目用于导航；系统最近文档列表用于发现外部文件。

打开只读取、验证、迁移并登记内存状态，不主动改写源文件。保存先通过 TaskDocumentCodec 验证和编码，再原子写入；写入成功后更新任务库。保存失败向界面传播，编辑中的数据保留在内存并显示错误。损坏文件保留错误条目，目录访问失败明确显示。

准备表单由具体 Task 对象驱动，避免布尔 sheet 在切换任务时捕获旧绑定。原任务快照在表单生命周期内保持稳定，检查与书签保存期间发生修改时拒绝覆盖；取消停止未提交的准备工作。

媒体使用设备本地只读书签。书签、模型、密钥和临时音频不写入 .voxline。文件是唯一持久成果。

## 验证

旧文件登记前后字节一致；非法任务及写入失败不会替换最后成功保存的文件。沙盒应用成功保存混合音视频 Task，重启后恢复全部条目与失败原因；打开媒体后任务文件字节保持一致。证据见 [混合媒体输入验证](../optimize/m1-media-input-validation.md)。
