# ADR-0006 单窗口任务库与显式持久化

状态：接受。日期：2026-10-03。

## 决定与理由

任务列表、准备和媒体详情共享一个原生窗口。TaskLibrary 管理 .voxline 文件生命周期，替代 ADR-0005 的 DocumentGroup / FileDocument 场景，使导航和处理成果使用同一个对象。

一个任务只维护一个成果文件：新任务保存在本地任务库，导入文件以原 URL 为保存目标。内存摘要服务于导航，系统最近文档服务于发现，不形成第二份成果存储。

保存先验证和编码，再原子写入。成功后才更新任务库；失败保留编辑状态与最后成功保存的文件。准备表单由具体 Task 驱动，防止切换任务后的旧绑定覆盖新数据。当前读写和准备生命周期统一见 [架构](../architecture/README.md)。
