# ADR-0017 停止执行后的任务参数修改

状态：接受。日期：2026-10-05。修订：2026-10-09。

## 决定与理由

冻结参数隔离服务默认值变化，任务本身仍允许明确修改。停止后允许更换转写方式、服务、模型与原文语言；历史识别保留实际使用的参数，后续请求使用当前配置。翻译参数可以独立调整，导出选项仅在导出时选择，解决服务失效、跨设备绑定和暂停后继续的实际需要。

参数修改只发生在执行者释放任务后。将任务当前配置与历史识别来源分开，避免失败服务或不合适模型把任务锁住。协议切换后重新规划未完成范围，裁除已完成音频，保存已有字幕与人工编辑；参数改变后不复用旧配置的失败识别。改变翻译设置时重新建立批次，保留同目标语言的校对译文；改变目标语言先确认替换译文，避免把旧语言成果作为新语言导出。不增加通用迁移策略、第二套队列或自动服务匹配。

两平台的编辑、绑定、译文影响和持久化规则统一见 [架构](../architecture/README.md#task-持久化)，页面规格见 [需求](../RFC/voxline-v1.md)。
