# ADR-0017 停止执行后的任务参数修改

状态：接受。日期：2026-10-05。

## 决定与理由

冻结参数隔离服务默认值变化，任务本身仍允许明确修改。已有转写成果保留其模型与原文语言；翻译和导出可以独立调整，解决服务失效、跨设备绑定和暂停后继续的实际需要。

参数修改只发生在执行者释放任务后，保存检查点与当前参数的一致性。改变翻译设置时重新建立批次，保留同目标语言的校对译文；改变目标语言先确认替换译文，避免把旧语言成果作为新语言导出。不增加通用迁移策略、第二套队列或自动服务匹配。

两平台的编辑、绑定、译文影响和持久化规则统一见 [架构](../architecture/README.md#task-持久化)，页面规格见 [需求](../RFC/voxline-v1.md)。
