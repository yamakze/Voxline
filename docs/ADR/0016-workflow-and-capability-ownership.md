# ADR-0016：处理编排与能力模块归属

状态：接受。日期：2026-10-04。

## 决定

处理编排和任务持久化归入 Workflow，模型、服务配置与原生导出归入各自能力模块。应用负责入口、主要页面与平台接线，底层模块不引用应用。

处理阶段事实来自媒体与检查点，界面只负责呈现。测试直接依赖被测能力包；平台会话及应用接线在应用测试中验证。

## 理由

把处理服务放在可执行目标中，会使复用和测试依赖整个 Mac 界面。明确能力归属后，两平台可以接入同一工作流，也能独立验证持久恢复、协议和原生媒体能力。

Mac 系统最近文档、Apple 视图翻译会话与 iOS 设备副本具有不同生命周期，由应用接线保留其产品语义。当前不需要通用存储策略、站点插件或多执行者调度框架。

当前职责与依赖规则见 [架构](../architecture/README.md)，两平台功能范围见 [ADR-0015](0015-ios-feature-parity.md)。
