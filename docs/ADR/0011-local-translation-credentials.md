# ADR-0011：本地服务元数据与 Keychain 凭据分离

状态：已接受。

Task 需要保留处理参数并跨文件迁移，API 密钥则只用于本机发起请求。将密钥写入服务 JSON 或任务成果会把凭据和可复制文件绑定；以 models 列表测试连接也不能证明选定模型支持实际聊天协议。

服务 JSON 只保存稳定 ID、名称、地址与默认模型，密钥以服务 ID 存入本机 Keychain。旧明文配置先完成全部钥匙串写入，再删除文件中的密钥字段；失败保留可恢复来源。保存配置失败需要恢复旧凭据，并明确报告恢复失败，不能发布不存在的成功配置。

Task 冻结服务地址、模型和目标语言，执行时只查找对应凭据；默认模型修改不改变历史任务。地址变更需要明确恢复配置，或停止执行后通过任务参数／服务绑定更新快照，决定见 [ADR-0017](0017-explicit-task-parameter-edits.md)。连接测试和实际字幕翻译共用聊天协议与严格结果检查。此决定不引入账户、跨设备执行或云冲突机制。

当前规则见 [架构](../architecture/README.md#本地服务与凭据)，验收结果统一见 [Project](https://github.com/users/yamakze/projects/1)。
