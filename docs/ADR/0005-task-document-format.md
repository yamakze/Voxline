# ADR-0005 本地 Task 文档格式与迁移

状态：接受。日期：2026-10-02。文档生命周期由 [ADR-0006](0006-single-window-task-library.md) 替代。

## 决定与理由

沿用 .voxline 扩展名，以版本 2 的 ProcessingTask 保存有序媒体、一次参数快照与独立成果。整体状态由媒体条目计算，避免重复状态失配；参数开始时冻结，默认设置变化不能改变既有任务。

版本 1 的 SubtitleProject 作为迁移输入。保留任务、媒体和字幕身份以及译文来源版本，继续复用设备书签；旧格式缺少处理完成证据，因此成果标为待确认。打开只读取与迁移，明确保存才写新版，避免仅浏览就修改原文件。

结构化 JSON 是成果权威来源，SRT 是导出物。非法或未来版本明确失败，不用空任务替代原内容。字段、验证、迁移和中断状态的当前规则统一见 [架构：Task 持久化](../architecture/README.md#task-持久化)。
