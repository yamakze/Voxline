# ADR-0005 本地 Task 文档格式与迁移

状态：接受。日期：2026-10-02。

## 决定

`.voxline` 保持原扩展名、类型标识和系统文档打开方式，格式版本 2 的根对象为 ProcessingTask。FileDocument 是应用读写入口，DocumentGroup 负责本地打开、保存和文档生命周期；当前任务查找继续使用系统 Open Recent。没有独立数据库或另一个任务存储副本。

Task 保存 ID、名称、有序媒体条目、参数和开始时间。整体状态与完成／失败数量由条目状态计算，不重复保存。媒体条目保存自身 ID、名称、音频／视频类型、本地来源描述、媒体身份、处理状态及字幕；字幕继续复用 SubtitleCue 的时间、稳定 ID、原文版本和译文来源。

参数只有一份：开始前通过 updateParameters 修改，freezeParameters 校验后记录开始时间并固定参数。冻结本身不运行 Provider，也不将媒体标为完成。参数包含转写模型、自动／指定原文语言、可选翻译设置与 SRT 类型。翻译服务 ID 引用本地服务配置；密钥与书签不进入 Task。

旧版本 1 由 ProjectDocumentCodec 验证，再迁移为 Task。已有媒体或字幕形成一个媒体条目，条目 ID 保留原项目 ID，从而继续读取既有本地书签；任务 ID、名称、媒体身份、字幕和设置保持原值。空白旧项目迁移为空 Task，不虚构文件或成果。

旧格式没有处理完成证据，因此迁移条目标记 needsReview，界面显示“已有成果，待确认”。已有字幕可浏览和继续关联媒体，迁移不声称执行完成。重新保存写版本 2；打开不会主动改写旧文件。

格式不支持、损坏、重复媒体 ID、非法来源、字幕时间或译文版本均显式失败。Task 与旧项目复用同一字幕时间线验证。写入先完成编码验证，再交给系统文档写入，失败不以空 Task 替代已有文件。

文档重新打开时，将保存的运行条目改为 interrupted，并保留阶段、已有字幕与参数。打开文档不重新创建执行者；队列调度和实际恢复由 VXL-026／012 实施。

## 交付边界

VXL-046 交付 Task 模型、参数快照、文档读写和迁移，以及既有单媒体视图对 Task 条目的适配。完整任务列表、创建参数页面和 Liquid Glass 由 VXL-047 交付；输入批量多选与音频解码由 VXL-006／034 交付。

验证见 [Task 文档与迁移结果](../optimize/m1-task-document-validation.md)。
