# ADR-0005 本地 Task 文档格式与迁移

状态：接受。日期：2026-10-02。文档生命周期由 [ADR-0006](0006-single-window-task-library.md) 替代；格式扩展见 [ADR-0010](0010-atomic-task-checkpoints.md)。

## 决定与理由

沿用 .voxline 扩展名，以版本 2 的 ProcessingTask 保存有序媒体、一次参数快照与独立成果。整体状态由媒体条目计算，避免重复状态失配；参数开始时冻结，默认设置变化不能改变既有任务。

版本 1 的 SubtitleProject 作为迁移输入。保留任务、媒体和字幕身份以及译文来源版本，继续复用设备书签；旧格式缺少处理完成证据，因此成果标为待确认。打开只读取与迁移，明确保存才写新版，避免仅浏览就修改原文件。

结构化 JSON 是成果权威来源，SRT 是导出物。非法或未来版本明确失败，不用空任务替代原内容。字段、验证、迁移和中断状态的当前规则统一见 [架构：Task 持久化](../architecture/README.md#task-持久化)。

## 版本 4 的翻译参数扩展

每批字幕数量和系统提示词属于 Task 的执行参数，服务设置变化不能改变已开始任务。版本 4 将两者与翻译地址、模型和目标语言一起保存，并在检查点中保持同一快照；较旧应用明确拒绝新版本，避免忽略参数继续执行。历史缺失字段迁移为原来的 30 句和翻译提示词。当前格式与迁移规则见 [架构](../architecture/README.md#翻译数量与提示词)。

## 版本 6 的云端识别扩展

音频聊天协议、时间来源和独立保存的识别结果改变了恢复语义，版本 6 将这些信息写入 Task。旧应用明确拒绝新版，避免忽略协议后重复识别或误用时间；新版继续读取版本 1～5，历史云端参数沿用 Audio Transcriptions 协议。当前规则见 [架构：云端转写](../architecture/README.md#云端转写)。
