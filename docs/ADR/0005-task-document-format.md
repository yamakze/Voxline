# ADR-0005 本地 Task 文档格式

状态：接受。当前开发格式决定更新于 2026-10-08。

ProcessingTask 以版本化 JSON 保存有序媒体、参数、检查点与字幕；整体状态由媒体条目计算。JSON 是成果权威来源，SRT 及视频为即时导出物，任务不冻结导出类型。

当前处于个人本地开发阶段，格式只支持当前版本，允许破坏式变更，不维护旧单媒体或旧 Task 的迁移分支。格式错误保留原文件与明确失败，不用空任务掩盖读取失败。

媒体身份使用大小及头尾采样指纹，模型清单摘要保持独立。字幕时间来源保存在识别证据，校对是可选编辑，完成状态不依赖确认标记；译文来源仅用于内部编辑保护。

当前规则见 [架构：Task 持久化](../architecture/README.md#task-持久化)，持久恢复理由见 [ADR-0010](0010-atomic-task-checkpoints.md)。
