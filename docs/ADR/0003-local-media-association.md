# ADR-0003 设备本地媒体关联

状态：接受。日期：2026-10-02。Task 根对象和媒体扫描策略由 [ADR-0004](0004-task-workflow-and-native-design.md) 更新。

## 决定与理由

媒体保持本地引用，不随任务复制。只读沙盒书签按媒体条目 ID 单独保存，Task 只保存内容身份和音轨；文件访问授权属于设备，不能作为可移植成果的一部分。

重新关联允许明确选择新的可解码媒体和音轨，包括同片源的不同清晰度文件。字幕与原始识别证据保留，恢复识别仍绑定原输入；已完成识别的翻译不依赖当前播放文件。媒体缓存采用文件大小及有界采样指纹，避免大文件导入的整文件读取。

确认书签后才提交关联；确认过程中源文件或任务变化时拒绝覆盖，避免产生部分关联。具体访问、缓存和更新规则统一见 [架构：输入与文件访问](../architecture/README.md#输入与文件访问)。
