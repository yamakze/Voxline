# ADR-0003 设备本地媒体关联

状态：接受。日期：2026-10-02。

范围更新：Task、平台、同步与媒体扫描策略以 [ADR-0004](0004-task-workflow-and-native-design.md) 为准；下文保存原决定及其实施背景。

## 决定

视频保持本地引用，首版仅导入 MP4、MOV、M4V。导入检查真实视频与音轨、时长、语言、编码、保护与解码状态；单一可解码音轨可作为唯一候选，多音轨必须明确选择，不自动混音。

媒体身份包含流式 SHA-256、字节数、时长与音轨 ID。既有项目重新关联时校验全部身份字段，允许相同内容改名；其他内容或音轨需新建项目。重新关联保留原文、译文、字幕 ID、时间和编辑版本，不以清空字幕修复不符。

本地关联按项目 ID 存为 Application Support 下的独立 JSON 记录，包含版本、媒体身份和只读安全范围书签。记录采用原子写入，不写进 `.voxline` 文档。打开项目解析书签并验证实际媒体；无本地记录提示关联，损坏或失效记录提示重新关联，过期书签验证成功后更新。

确认前再次检查文件，书签保存成功后才提交文档变更；等待期间项目或媒体已变化则显式拒绝提交。读入时检查文件大小与修改时间，避免将检查期间变动的文件当作稳定身份。

项目列表复用 DocumentGroup 与系统最近文档入口，当前检索需求不引入 SwiftData。另一设备无本地书签时可选择相同视频建立关联；真实跨设备与 iCloud 链路在同步任务验收。

依据：[首版需求](../RFC/voxline-v1.md)、[当前工程边界](../architecture/README.md)。
