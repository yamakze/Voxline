# ADR-0019：恢复 iCloud 同步与云端转写范围

状态：接受。日期：2026-10-06。修订：2026-10-07。

## 决定

iCloud Task／字幕同步、离线冲突恢复与同步设置重新纳入 Mac／iOS 后续交付，复用 VXL-018、019、022。此决定替代 ADR-0004、ADR-0015 的同步暂废弃范围，不改变已交付的本地模式与手动文件交接。

采用原生 iCloud 文档能力，保留 Task 与字幕成果的单一权威文档。同步已提交成果与参数，设备访问、凭据、模型、临时数据和执行占用保持本地；原音视频默认保持引用，通过明确设置选择同步。实际冲突保留可恢复文档版本，不自动合并字幕或引入执行租约。两设备通过原生文件选择器授权同一个 iCloud Drive 文件夹，使用设备本地书签恢复访问；不采用应用专属 iCloud 容器。原生文件协调、按需下载、冲突版本、离线编辑及真实设备往返属于必要验收。

VXL-024 云端转写恢复为可独立实施的路线，不再等待 Apple 本地翻译的全部系统验收。首个服务采用 OpenAI Audio Transcriptions 的 whisper-1 协议，以 verbose_json 的段时间戳接入，复用媒体提取、Provider、字幕切分、检查点和翻译流程；云端服务配置及任务选择按设备原生设置交付。实际上传、处理、取消与恢复按服务能力记录，不假定聊天接口兼容转写。

VXL-044 的本地索引与替代存储候选保持独立暂缓。采用 iCloud 文档同步不自动引入 SwiftData、CloudKit 或通用同步框架。

## 理由

自动同步减少 Mac 与 iOS 校对成果的手动往返；原生文档与明确版本选择满足个人使用的成果保护。共享 iCloud Drive 文件夹保留免费开发账号与 AltStore 安装路线，避免依赖应用专属容器的跨平台 provisioning 授权。云端转写为设备资源或处理速度提供独立选择，其接入不依赖本机翻译语言资产。
