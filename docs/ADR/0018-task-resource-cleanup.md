# ADR-0018：Task 删除与派生资源清理分离

状态：已接受。修订：2026-10-08。

Task 文档是用户成果，设备关联和派生缓存使用独立目录。缓存可能被系统清理、损坏或无法读取，不应把缓存可验证性作为删除用户文档的前置。

共享任务库先核对已知活动任务及副本引用，删除文档后按媒体 ID 清理未共享资源。清理失败显示具体路径，任务文档删除仍然成立；无法确认其他文档引用时保留派生资源。旧平铺证据没有可靠归属，不再扫描解码，也不据此阻止删除。

原生媒体和 Provider 继续负责生成资源，清理只接触明确的应用目录。原媒体、其他任务副本、导出物、共用模型、翻译服务与密钥不属于本操作。不建立删除日志、后台垃圾回收或跨设备协议。

这一选择替代原先“全部缓存清理成功后才删除文档”的顺序，解除历史缓存对用户操作的阻断。当前规则见 [架构](../architecture/README.md)，产品范围见 [需求](../RFC/voxline-v1.md)，实施与验收由 VXL-060 跟踪。
