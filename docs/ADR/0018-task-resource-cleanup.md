# ADR-0018：Task 所属资源清理

状态：已接受。

Task 文档、设备媒体授权、派生 PCM 与独立转写证据使用不同目录。只删除文档会持续遗留设备存储；同 ID 副本与迁移媒体又可能共用这些资源。

两平台由共享任务库组织删除，清理前检查已知任务文件及副本的引用。原生媒体和 Provider 继续负责生成资源，删除操作只接触明确的应用资源目录及媒体 ID。队列将媒体 ID 直接传入 Provider，独立证据按该 ID 存放；历史平铺证据只能依持久检查点的完整内容确认，无法确认归属时保留。

资源清理和排序记录成功后才删除 Task 文件。失败时任务文件与媒体 ID 仍在，可显示具体失败项并在重启后重试。部分缓存已经清理不回滚；如果继续处理，需按实际访问状态重新关联媒体或提取缓存。这一顺序避免另建删除日志、后台垃圾回收或跨设备协议。

原媒体、其他已知任务引用的资源、导出物、共用模型、翻译服务与密钥不属于本操作。Mac 删除实际打开的任务文件；iOS 删除导入后保存的设备副本。系统最近文档与排序记录由各自现有入口维护。

当前规则见 [架构](../architecture/README.md)，产品范围见 [需求](../RFC/voxline-v1.md)，实施与验收由 VXL-060 跟踪。
